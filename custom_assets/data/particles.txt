# Particle systems (dusk_formats::content::particles, docs/visuals.md). Used by map sprites
# (sprite_fx.txt `particles` lines) and spell kits (data/spell_visuals.txt `particles=`).
#
#   sprite        atlas cell 0..15 of fx_particles.png (4x4, row-major):
#                  0 soft blob   1 sparkle cluster  2 six-ray star   3 small burst
#                  4 thin cross  5 solid star       6 eight-ray flare 7 small soft glow
#                  8 smoke clump 9 spiky starburst 10 bright flare   11 hollow ring
#                 12 smoke puff 13 flat disc       14 small disc     15 sleep "Z"
#   blend         add | alpha
#   emission      particles per second;  lifetime: seconds the system emits (<= 0 = until stopped)
#   life          particle life min,max (s)
#   direction     degrees, 0 = up on screen, clockwise;  spread: full cone width (degrees)
#   relative      1 = add the emitter's direction of movement
#   speed         px/s min,max;  gravity: px/s^2 (+ = down);  radial: px/s^2 away from the emitter;
#   tangential    px/s^2 sideways
#   size          start,end,variation (x 32 px);  spin: start,end,variation (not drawn)
#   color_start / color_end   r,g,b,a 0..1;  color_var / alpha_var: 0..1 start randomisation
#
# Art rules (docs/world.md): only fire glows; ember, rust, oxblood, dull bone; nothing near-white.
