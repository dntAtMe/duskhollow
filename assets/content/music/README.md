# Custom soundtrack

Background music added by the project owner (not from the original game). Played instead of the
original music on custom maps (`custom_*`) and everywhere with `--art custom`; tracks rotate
randomly with crossfades (see `crates/dusk_client/src/audio.rs`).

| File | Title |
|---|---|
| `tenebrae.mp3` | Tenebrae |
| `sous_les_voutes.mp3` | Sous les voûtes |
| `minor_modal_motif.mp3` | Minor Modal Motif |

Adding a track: drop an `.mp3` or `.ogg` into this folder.
